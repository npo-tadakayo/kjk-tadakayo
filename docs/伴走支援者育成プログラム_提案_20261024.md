## 1. 結論（推奨）

**CRM の中に「育成コース」画面（`/learning.html`）を1つ作り、そこを入口にして、7つのステップを順に進めてもらう。最後のステップは、いまある「評価シート → バッジ付与」をそのまま使う。**

```
STEP1 はじめに ─ STEP2 介護情報基盤を知る ─ STEP3 伴走支援の手順 ─ STEP4 CRMの使い方
   └ 動画＋確認テスト（各ステップ）……………………………………………… ここまで「ひとりで」進める
STEP5 練習モードで実技（CRMの課題を自動で判定）
STEP6 ロールプレイ・見学（トレーナー立会い・任意）
STEP7 OJT ＝ スキルチェック（評価シート）→ 独り立ち可 → 伴走支援者バッジ ＝ 独り立ち
```

理由:
1. **評価とバッジの仕組みはもう本番にある**（`supportEvaluations`・`supportBadges`・案件の「伴走支援」タブ）。足りないのは「OJTに来るまでの準備」と「いまどこまで進んだか」が見えることだけ。新しい評価の仕組みを作らず、**前半（STEP1〜5）を足して後ろにつなぐ**のが一番小さく、一番ぶれない。
2. 練習生ロールは本番を見られないが、**動画（Storage `training/`）と練習モードは使える**。つまり、新人が自分ひとりで進められる学習環境は、すでに半分できている。
3. 育成のとりまとめ（蜂須賀さん）とトレーナー4名が、**「誰が・どこまで進んで・OJTに入れるか」を一覧で見られる**と、OJTの割当てが組みやすい（11/9・10 の大分の現地OJTのような機会に、準備の済んだ人を当てられる）。

## 3. 7つのステップ（教材・合格の条件）

## 4. 画面とデータ

### 4.1 新しい画面「育成コース」 `/learning.html`（サイドバーに追加）

- **本人の画面**: 7つのステップが縦に並び、今のステップが開いている。動画はその場で再生（`video-player.js` を流用）、テストもその場で受けられる。済んだステップには日付とチェック。いちばん上に「次にやること」を1行で出す。
- **トレーナー・管理者の画面（同じページの下側）**: 受講中の人の一覧（名前・いまのSTEP・最後に進んだ日・「OJTに入れます」）。一覧から、その人の進み具合を開ける。
- バッジを付与された人には「独り立ち」の表示（付与日・認定したトレーナー）。

### 4.2 データ（本番DBに1コレクション追加）

`learningProgress/{メール}`（1人1文書）

```
{ name, startedAt,
  videos:   { "S1-A": { maxPos, duration, doneAt }, "PART0": {...}, "U1": {...} },
  quizzes:  { "S1": { best, passedAt, attempts }, ... },
  pledgeAt,                  // STEP1「約束」への同意
  practice: { checkedAt, items: { firstContact: true, visitDate: true, ... } },
  readyForOjtAt,             // STEP1〜5 が全部済んだ日時
  updatedAt }
```

- 置き場所は**本番DB**。練習DBは毎晩3時に初期化されるので、進み具合が消えてしまう。
- **ルールの追加が要る**（`firestore.rules`・約12行）: 本人は自分の文書だけ読み書きできる（**練習生も**。練習生は本番の他のものは今までどおり見られない）／登録スタッフは全員分を読める（トレーナーの一覧のため）／削除は管理者だけ。末尾の「その他すべて」の書き込み対象から外す。
  - ⚠ 本人が自分の記録を書く方式なので、**やろうと思えば「済」にできてしまう**。ただし最後の関門はトレーナーが現地で見る OJT なので、ここは「自分の学習の記録」と割り切る（動画の視聴は早送りも防がない）。
- 確認テストの問題と正解は画面側のファイル（`admin/js/learning-catalog.js`）に置く。**正解が画面から見えてしまう**が、上と同じ理由で割り切る。
- **利用者（被保険者）の情報は一切入れない**（入るのは職員本人の学習の記録だけ）。

### 4.3 練習モードの課題の自動判定（STEP5）

練習モードで「判定する」を押すと、**練習DBの自分の担当の案件**を読んで、次が入っているかを確かめ、結果だけを本番の `learningProgress` に書く。

| 課題 | 判定 |
|---|---|
| 初期連絡を記録した | 対応記録が1件以上 |
| 訪問予定日を入れた | 案件の訪問予定日あり |
| 伴走支援タブの事前確認をつけた | 事前確認のチェックが全部 |
| 当日〜書類チェックをつけた | 当日・書類のチェックが全部 |
| 実施の記録を残した | 実施日・実施者・区分あり |
| ステータスを「伴走支援」以降に進めた | ステータス |

- 練習のデータはログアウトで消えるので、**消える前に判定して結果だけ残す**。画面に「ログアウトの前に判定を押してください」と出す。
- 実装は画面側だけ（`functions/` は触らない）。

### 4.4 既存の画面へのつなぎ

| 画面 | 足すもの |
