# 介護情報基盤CRM 改訂のお知らせ（2026年9月14日）

NPO法人タダカヨ　2026年9月14日

伴走支援担当のみなさまへ。CRMに機能追加と修正を行いました。**操作マニュアルは差し替え済み**です。
**説明動画は順次差し替え中**で、いまの動画には画面名が古いものがあります。下の「動画と実際の画面が違うところ」を必ずご確認ください。

---

## 1. 新しくできるようになったこと

### スタッフが電話相談から見積もりを作れます

Webからの申し込みを待たずに、案件詳細の見積もりカード「**見積もりを作る**」から、電話で受けた相談の見積書をその場で作れます。
金額はサーバー側で自動計算され、事業所へ知らせたいときはメール送付も選べます。

作った見積書は「**見積書を表示**」から、印刷・PDF保存・事業所への送付ができます（見積もりツールと同じ体裁です）。

### 同一法人の複数事業所をまとめて見積もれます

見積もりツールに「**＋同一法人の事業所を追加**」ボタンが増えました（最大10事業所）。
法人名・担当者などの共通情報を1回入れるだけで、**事業所ごとに見積書1枚＋法人合計の表**ができます。
メールは1通にすべてのPDFがまとまって届きます。

### LPフォームに「ご希望」の必須項目が増えました

問い合わせフォームに「**まず相談したい／見積書がほしい／正式に申込みたい**」の3択が必須で入りました。
「**正式に申込みたい**」を選んだ事業所は、見積もりツールへ案内され発行後すぐ申込画面が開くため、**優先して対応してください**。
案件一覧・案件詳細にバッジと絞り込みが増えています。

### 案件詳細に「次の一手」、ホームに「はじめての方へ」

案件詳細のヘッダー直下に、今のステータスから**次にやることが1行**、飛び先ボタンが1つ出るようになりました。
初めてログインした人には、ホーム画面に「はじめての方へ」3ステップの案内が出ます（「わかりました」で次回から出なくなります）。

### 出荷に「キャンセルにする」を追加しました

発送済・請求済の出荷を取り消したいとき、これまでは削除しかありませんでした。
理由（事業所の都合／重複登録／誤登録／その他）を付けて記録を残したまま**「キャンセルにする」**が使えます。
**「この出荷を削除」は下書きの出荷だけ**に限定しました（発送済以降はキャンセルをお使いください）。

### 保管場所ごとに在庫を管理できます

仕入れた在庫の置き場所が複数になったため、「在庫・発注」タブで保管場所（名前・都道府県）を登録し、
出荷・入荷のたびにどこから出す／どこへ入れるかを選べるようにしました。
配送方法に「**郵送なし（手渡し・持参）**」も追加しています。

### 請求書メールの宛先が自動で入るようになりました

これまで宛先が空欄で出て毎回手入力していましたが、
「**認定事業者のメール → 出荷の送付先メール → 案件の担当者メール**」の順で自動で入るようになりました（入ったあとも直せます）。

### 請求書に支援報告書を同封できます

案件が紐づいた出荷の請求書メールに「**支援報告書も同封する**」チェックが増えました。
チェックすると、事業所向けの支援報告書（社内の対応履歴は載りません）がもう1つPDFで添付されます。

## 2. 直したこと

### 消費税の二重計算を是正しました

事業所への直接請求は、見積もりの税込金額に**さらに10%を上乗せしてしまっていました**。
いまは**事業所への直接請求は税込・認定事業者への卸は税別**で、正しく計算されます。誤った請求書はまだ送っていません。

### 請求書・領収証の書式を整えました

発行元の連絡先、品名ごとの用途説明を追加し、表題を「**領収証**」に統一しました。インボイスの登録番号も印字されます。

## 3. 動画と実際の画面が違うところ

**マニュアルは最新に差し替え済みですが、動画8本の撮り直しはこれから順に行います。** それまでは、動画に映っている名前と、いまの画面の名前が下のように違います。手順そのものは変わっていません。

| 動画に映っている名前 | いまの画面での名前 |
|---|---|
| 供給管理 | 「出荷・請求・入金」「在庫・発注」（2つのメニューに分かれました） |
| ダッシュボード | ホーム（今日やること） |
| 出荷を確定 | 発送済にする |
| 領収書 | 領収証 |
| 入金記録 | 入金を記録する |
| 修正 | 送付先・数量を直す |
| 種別変更 | 請求先を変える |

> 動画を見ていて「あれ、この画面にこのボタンがない」と思ったら、上の表を確認してください。それでも分からないときは伴走支援チームまでご連絡ください。
