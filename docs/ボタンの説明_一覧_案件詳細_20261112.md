# ボタンの説明（吹き出し）一覧 — 案件詳細の画面（2026-11-12）

**何のためのファイルか**: 案件詳細の画面（`admin/case-detail.html`）のボタンにマウスを乗せる（スマホは長押し・キーボードはフォーカス）と出る説明文の一覧です。言い回しを直したいときは、この表で直したい行を探し、右の「ファイル」の同じ文を書き換えてください（このファイルは一覧で、画面はこのファイルを読みません）。

- 次田さん決定（2026-11-12）: 各ボタンに説明の吹き出しを付ける。まず案件詳細の画面から。評判を見て他の画面へ広げる
- 仕組み: ボタンに `data-tip="説明文"` を付けると、`admin/js/tooltip.js`（部品）が吹き出しを出す。色・角丸は `admin/css/crm.css` の `.kjk-tip`
- 説明文は、そのボタンを押したときの今の動き（右の「根拠にしたコード」）を読んでから書いた。1〜2文・です／ます。押すと何が起きるか（取り消せるか、メールや Chat が出るか、どこに記録が残るか）を書いている
- 練習モードではメール・Chat は実際には出ません（「送ったことにする」だけ）。説明文は本番の動きで書いています
- 説明文に `"` `<` `>` と改行は使えません（`scripts/test-tooltip.mjs` が確かめます）。かぎかっこは「」を使ってください
- 新しいボタンを足したら、`data-tip` も付けてください。付け忘れは `scripts/test-tooltip.mjs` が見つけます（このファイルにも行を足す）
- 2026-11-12 追加（承諾書のサイン＝発注・設定 `orderByConsent` がオンのときだけ出るボタン）: 見積もりカードの「承諾書を印刷」ほか10行（対応記録タブの表の末尾）
- 同じ説明のボタン（「見積もりを作る」の2か所、「コピー／URLをコピー」の2か所、統合の画面の「×」「キャンセル」）は1行にまとめています

## 他の画面へ広げるとき

1. その画面の HTML の末尾に `<script src="/js/tooltip.js" type="module"></script>` を足す
2. ボタンに `data-tip="…"` を付ける（JS で描くボタンも同じ。後から描いても効く）
3. `scripts/test-tooltip.mjs` の `FILES` にその画面のファイルを足し、この一覧に表を足す
