- ご依頼主は、設定（`appConfig/settings` の `senders`）の**先頭の1件**が既定。複数あれば画面上の選択肢で切り替える（`admin/js/letterpack-print.js` の `sendersOf`）。
- 設定に差出人が無いときは、請求書の発行者情報 → 既定（NPO法人タダカヨ　介護情報基盤伴走支援事業・東京都大田区大森・**050-6872-9884**）の順で使う。
- 倉庫の画面の宛名（`admin/js/warehouse-print.js`）は、`warehouse-rules.js` の `senderForLabel` が**先頭の1件だけ**を使う。
- 出荷には「出荷元」（`originLocationName`）が入る。保管場所には、郵便番号・住所・宛名・電話を登録できる（MANUAL 2026-09-30）。ただし、宛名印刷のご依頼主には**使われていない**。

つまり、いまのご依頼主は、出荷元が滋賀でも沖縄でも、設定の先頭の差出人（大森・代表電話）になる。藤田さんが電話番号を手書きしているのは、このため。

## 案

### 案A：設定を変えるだけ（コードの変更なし）
設定の差出人に「滋賀ロジスティクスセンター」（住所と、電話 050-1808-2999）を追加し、**先頭**に置く。
- 長所：今日中にできる。
- 短所：出荷元が滋賀以外（沖縄・宮崎など）の出荷も、滋賀の名義になる。請求書の発行者などで先頭の差出人を使う画面があれば、そこにも影響しないか確認が必要。

### 案B：ご依頼主を、出荷元の保管場所から自動で決める（推奨）
- 滋賀の保管場所に、住所（〒520-0013 大津市勤学2丁目9-3）・宛名（滋賀ロジスティクスセンター）・電話（050-1808-2999）を登録する。
- レターパックの宛名・倉庫の宛名・発注書の送付状で、ご依頼主は、**出荷元の保管場所に住所と電話があればそれを使う**。無ければ、いまの設定の差出人を使う（これまでと同じ）。
- 画面で差出人を手で切り替える選択肢は、そのまま残す。
- 変更するファイル（予定）：`admin/js/letterpack-print.js`、`admin/js/warehouse-print.js`、`admin/js/warehouse-rules.js`（`senderForLabel` に出荷元を渡す）、`functions/warehouse-rules.mjs`（倉庫の画面が返す差出人）。保管場所の項目名（郵便番号・住所・宛名・電話）は、実装時にコードで確認する。
- 長所：沖縄・宮崎など、出荷元ごとに正しいご依頼主・電話になる。手書きが要らなくなる。
- 短所：コードの変更とテスト（`scripts/test-warehouse-ui.mjs`・rules のテスト）が要る。

### 案C：出荷ごとに差出人を保存する
画面で選んだ差出人を、出荷に保存して、次回以降も同じにする。
- 案Bのほうが、操作が要らないので、こちらは見送りを提案。

## おすすめ
**案A → 案Bの順**。案Aで、藤田さんの手書きを今日からなくす。そのあとに案Bで、出荷元ごとに自動で決まるようにする。
